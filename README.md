### 👨‍💻 Sobre mí

Soy desarrollador de software autodidacta, con especial interés en la construcción de **sistemas de gestión, aplicaciones empresariales y herramientas que automatizan procesos**.

Trabajo principalmente con el ecosistema **C# y .NET**. Me interesan el diseño de APIs, el modelado de dominio, la organización de soluciones mantenibles y la evolución continua de los productos. También comparto contenido relacionado con programación a través de mis canales.

### 🛠️ Tecnologías y áreas de trabajo

- **Backend:** C#, .NET, ASP.NET Core, Entity Framework Core.
- **Datos:** PostgreSQL y modelado de bases de datos relacionales.
- **Frontend:** Blazor, HTML, CSS y Bootstrap.
- **Herramientas:** Git, Docker y Visual Studio.
- **Arquitectura y prácticas:** arquitectura modular, Domain-Driven Design (DDD), Vertical Slice Architecture (VSA) y CQRS.
- **Experiencia adicional:** MAUI y desarrollo Android.
