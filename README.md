### 👨‍💻 Sobre mí

Soy desarrollador de software autodidacta, enfocado en **aplicaciones empresariales, plataformas SaaS y soluciones a medida**.

Trabajo principalmente con **C# y .NET**, desde el modelado de dominio y las APIs hasta la persistencia de datos, la integración de interfaces y el despliegue. Me interesa desarrollar productos mantenibles, escalables y adaptados a las necesidades de quienes los utilizan.

### 🛠️ Tecnologías y áreas de trabajo

- **Backend:** C#, .NET, ASP.NET Core, Minimal APIs y Entity Framework Core.
- **Frontend:** Blazor, React, TypeScript, HTML, CSS y Tailwind CSS.
- **Datos:** PostgreSQL y modelado de bases de datos relacionales.
- **Infraestructura y herramientas:** Docker, Docker Compose, Git y Visual Studio.
- **Arquitectura y prácticas:** Domain-Driven Design (DDD), arquitectura modular, Vertical Slice Architecture (VSA) y CQRS.
- **Experiencia adicional:** .NET MAUI y desarrollo Android.

### 🚀 Proyectos destacados

#### Plataformas SaaS

**SGAA — Sistema de Gestión de Auditorías y Aseguramientos**  
**Estado:** En producción · **Código:** Privado

Plataforma para gestionar trabajos de auditoría y aseguramiento: clientes, encargos, equipos, fases, procedimientos, seguimiento, supervisión y control de calidad. Contempla un modelo multiempresa con separación de información por organización.

🔗 [Sitio público de referencia](https://redfor-ti.com.py/)

**AuditaPy**  
**Estado:** Segunda versión en desarrollo · **Código:** Privado

Evolución de la solución de auditoría hacia una nueva generación de plataforma SaaS, enfocada en modernización tecnológica, automatización de procesos y mejora de la experiencia de gestión.

**ControlLote — Auditoría y Conciliación de Comisiones**  
**Estado:** Desarrollo privado · **Código:** Privado

Plataforma SaaS orientada a la auditoría financiera de comisiones inmobiliarias. Procesa reportes PDF, aplica reglas contractuales, compara comisiones informadas y esperadas, identifica posibles inconsistencias y facilita el análisis mediante indicadores y reportes.

#### Desarrollo de software para clientes

**BoozHome — Plataforma Inmobiliaria**  
**Modalidad:** Desarrollo exclusivo para un cliente · **Estado:** Implementación avanzada y verificación local · **Código:** Privado

Solución web con catálogo público de propiedades, páginas de detalle, contacto por WhatsApp y un panel administrativo para la gestión inmobiliaria. Incluye funcionalidades de usuarios, fotografías, estados y analíticas. Desarrollada con **.NET 10, Blazor, PostgreSQL y Tailwind CSS**; su despliegue de producción está pendiente.
